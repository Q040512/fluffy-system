# Xianxia Valley MVP

一个用 Godot 4 搭建的 2D 像素风修仙种田原型，核心闭环是：

- 四向移动
- 灵田开垦、播种、引灵、成熟、收获
- 游戏内时间 / 时辰 / 天象流转
- 灵力消耗与打坐恢复
- 背包、灵石收益
- 基础 NPC 社交与野外采集
- JSON 存档

## 运行方式

1. 安装 Godot 4.x。
2. 用 Godot 导入仓库中的 `game/` 目录（例如当前仓库路径下的 `/workspace/fluffy-system/game`）。
3. 打开后直接运行主场景 `res://scenes/main.tscn`（项目根在 `game/` 时该路径可直接使用）。

## 当前操作

- `WASD` / 方向键：移动
- `E` / `空格`：交互
- `R`：打坐，恢复灵力并推进时间

## MVP 内容

- 3x3 灵田
- 2 种灵植：青灵草、赤火芝
- 1 个宗门 NPC：青岚师姐
- 1 个野外采集点：山壁灵草
- 自动存档：`user://savegame.json`
