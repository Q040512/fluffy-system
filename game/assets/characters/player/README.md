# Player Sprite Pipeline

这个目录预留给主角像素资源。

推荐结构：

- `walk_down_0.png` ~ `walk_down_3.png`
- `walk_up_0.png` ~ `walk_up_3.png`
- `walk_left_0.png` ~ `walk_left_3.png`
- `walk_right_0.png` ~ `walk_right_3.png`
- `idle_down.png`
- `idle_up.png`
- `idle_left.png`
- `idle_right.png`
- `meditate.png`

建议：

- 单帧尺寸：`32x48`
- 基准点：脚底居中
- 透明背景 PNG
- 朝向命名固定，方便后续自动装配
