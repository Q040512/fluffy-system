# Crop Sprite Pipeline

这个目录预留给灵植像素资源。

推荐每种作物一个子目录，例如：

- `qingling_grass/stage_0.png`
- `qingling_grass/stage_1.png`
- `qingling_grass/stage_2.png`
- `qingling_grass/stage_ready.png`
- `chihuo_zhi/stage_0.png`
- `chihuo_zhi/stage_1.png`
- `chihuo_zhi/stage_2.png`
- `chihuo_zhi/stage_ready.png`

建议：

- 单帧尺寸：`24x24` 或 `32x32`
- 保留透明边距，方便发光和缩放
- 成熟帧单独命名为 `stage_ready.png`
